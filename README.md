# AI Resume Parser

A Resume Parser built using Python and Streamlit that extracts candidate information from PDF resumes and displays it in a structured format.

## Features

- Upload multiple PDF resumes
- Extract candidate names
- Extract skills
- Identify fresher and experienced candidates
- Search candidates by skill
- Download data as CSV, Excel, and JSON

## Technologies Used

- Python
- Streamlit
- Pandas
- pdfplumber
- OpenPyXL

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Project Use Cases

- Recruitment automation
- Resume screening
- Candidate shortlisting
- Resume data organization
